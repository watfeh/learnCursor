# SINE Digital Client Portal

This project is a client portal for SINE Digital, designed to provide access to various projects in a tile format. Each tile represents a different project with details such as title, status, progress, and description.

## Features

- **Responsive Design**: Adapts to different screen sizes.
- **Project Dashboard**: Displays projects in a grid layout.
- **Interactive Tiles**: Hover effects and progress indicators.

## Technologies Used

- **React**: For building the user interface.
- **Next.js**: For server-side rendering and routing.
- **Material-UI**: For UI components and styling.
